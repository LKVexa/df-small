# schemas/

JSON schemas for every DF artifact. `./VERIFY` (gate G2) validates each artifact against the schema shipped beside it with the stdlib-only validator in `adapter/dfabric/schemas.py`.

* `DF_CAPABILITY_LEDGER.json`
* `DF_GATE_RESULTS.json`
* `DF_NODES.json`
* `DF_NODE_DESCRIPTOR.json`
* `DF_PACKAGE_MANIFEST.json`
* `DF_PROVENANCE.json`
* `DF_SOURCE_AUTHORITY.json`
* `DF_TRANSLATION_CORPUS_RECORD.json`
